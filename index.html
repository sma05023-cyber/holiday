📂 인사기록 엑셀 파일을 이 곳으로 클릭 또는 드래그하여 업로드하세요.

지원 형식: .xlsx, .xls

📌 사용설명서

  1. 전년도 근무상황관리-> 기타, 완결로 놓고 조회 후(엑셀 다운로드) → 업로드
  2. 교육공무직등인사 -> 인사기록 → 인사기록관리 → 인사기록(엑셀 다운로드) → 업로드
  3. 소정근로일수 수기 조정 필요 시 입력(선거 등)(엑셀 서식도 다운로드 후 시트2 조정 필요)
  4. 기준일 설정 후 계산 → 확인 후 엑셀 다운로드
  5. 1년 이상 근로자만 작성하세요.(근로기준법 제60조제2항 미구현)
  6. 전임경력은 반드시 검토하세요.
  7. STEP1에서 방학중 비근무일을 먼저 계산하면 소정근로일수에 자동 반영됩니다.
  8. 인사기록에는 있지만 STEP1 방학중 비근무일 목록에 이름이 없는 인원(상시근로자 등)은 STEP1·STEP2 개별 조정은 적용하지 않습니다.
  9. 소정근로일수 기준값은 공공데이터 특일 정보 API를 통해 매년 자동 산출됩니다(법정공휴일·대체공휴일·선거일 및 근로자의 날 반영). API 호출이 실패하면 기본값(243/244일)으로 계산됩니다.
  10. 인사기록 G열의 주민번호 앞 6자리를 읽어 생년월일(19YY-MM-DD)을 자동 산출, 엑셀 서식 F열에 반영합니다.
  11. 엑셀 서식은 20번째까지 자동 입력, 다운로드 가능합니다.
